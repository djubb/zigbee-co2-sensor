# Zigbee CO2 Сенсор с питанием от АКБ

Zigbee-устройство на базе ESP32-C6 для измерения CO2, температуры и влажности.
Питается от LiPo-аккумулятора, заряжается через USB-C.

---

> Форк проекта [florianL21/zigbee-co2-sensor](https://github.com/florianL21/zigbee-co2-sensor).
> Адаптирован под питание от аккумулятора и ESP32-C6 SuperMini.

---

## Возможности

- Измерение **CO2**, **температуры** и **влажности** (Sensirion SCD-41)
- Передача данных по **Zigbee** каждые 5 минут
- Интеграция с **Home Assistant** (ZHA)
- Питание от **LiPo 1500 mAh** — встроенная зарядка через USB-C
- Лёгкий сон (light sleep) между измерениями для экономии энергии
- Мониторинг уровня заряда батареи (требует внешнего делителя напряжения)

## Железо

| Компонент | Модель |
| --------- | ------ |
| Контроллер | [ESP32-C6 SuperMini](https://www.aliexpress.com/item/1005006325592150.html) |
| Сенсор CO2 | Sensirion SCD-41 (breakout) |
| Аккумулятор | LiPo 3.7V 1500 mAh |


## Подключение

SCD-41 подключается напрямую через штырьковые контакты (без проводов).
Порядок пинов на SuperMini совпадает с порядком пинов SCD-41:

```text
ESP32-C6 SuperMini:   GND  —  3V3  —  GPIO20  —  GPIO19
SCD-41 breakout:      GND  —  VCC  —  SCL     —  SDA
```

Аккумулятор подключается к пинам `B+` / `B-` на плате SuperMini.
Зарядка происходит автоматически при подключении USB-C — встроенный контроллер заряда
ограничивает напряжение ~4 В (защита от перезаряда).

### Делитель напряжения для мониторинга АКБ (опционально)

Для отображения уровня заряда в Home Assistant:

```text
B+  ── 2 МОм ──┬── 2 МОм ── GND
               │
             GPIO0 (ADC)
```

После установки резисторов обновить в [main/config.h](main/config.h):

```c
#define BATTERY_ADC_CHANNEL  ADC_CHANNEL_0   // GPIO0
#define BATTERY_VOLTAGE_DIVIDER 2
```

## Прошивка

Прошить можно прямо в браузере (Chrome / Edge):

**[Открыть веб-прошивалку](https://djubb.github.io/zigbee-co2-sensor/)**

1. Подключите ESP32-C6 по USB
2. Нажмите кнопку «Install»
3. Выберите COM-порт устройства
4. Дождитесь окончания прошивки

Если устройство не определяется — зажмите кнопку **BOOT** перед подключением USB.

> **Примечание:** во время light sleep USB Serial/JTAG также спит — COM-порт временно
> исчезает с хоста. Это нормально, не краш.

## Сборка из исходников

Требуется [ESP-IDF v5.3+](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/index.html).

```bash
git clone --recursive https://github.com/djubb/zigbee-co2-sensor.git
cd zigbee-co2-sensor
idf.py set-target esp32c6
idf.py build
idf.py flash
```

## Подключение к Home Assistant

1. Перейдите в **Настройки → Устройства и службы → ZHA**
2. Нажмите **Добавить устройство**
3. Включите питание сенсора — он автоматически войдёт в режим сопряжения
4. После подключения будут доступны: CO2 (ppm), температура (°C), влажность (%)

## Сброс к заводским настройкам

Если нужно отвязать устройство от координатора:

- Удалите устройство из ZHA-интерфейса — сенсор перейдёт в режим ожидания сопряжения
- Либо сотрите flash: `idf.py erase-flash`, затем прошейте заново

> При смене конфигурации Zigbee-кластеров необходимо стирать flash во избежание
> boot loop из-за несовместимости NVS-хранилища.

## Потребление энергии

Режим **light sleep** (текущий):

| Режим | Ток |
| ----- | --- |
| Измерение (SCD-41 + радио) | ~20–100 мА (пик, ~5 сек) |
| Light sleep | ~0.8 мА |
| Среднее | ~800 мкА |

С аккумулятором 1500 mAh: **~1900 часов ≈ 2.5 месяца**

Режим **deep sleep** (в разработке, требует MOSFET для отключения SCD-41):

| Режим | Ток |
| ----- | --- |
| Deep sleep | ~7 мкА |
| Среднее (интервал 10 мин) | ~70 мкА |

С аккумулятором 1500 mAh: **~2 года+**
